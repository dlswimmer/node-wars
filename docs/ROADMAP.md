# Roadmap

The game grows outward in scale: **battle → zone → region → country → world**. Each layer reuses the
one below it: winning battles captures zones, holding zones earns region bonuses, and so on.

## Phase 1: Skirmish (current)

One battlefield, bases ("nodes") that produce troops, swarms that capture them.

- [x] Bases with production, capacity, and capture
- [x] Swarm units that fly between bases
- [x] Special bases granting army-wide bonuses (Factory, Radar, Armory)
- [x] Simple AI opponent
- [x] Mouse and touch controls (drag, multi-select drag, tap-tap)
- [x] Win/lose screen
- [ ] Sound effects and music
- [ ] Difficulty setting (Recruit / Soldier / General)
- [ ] Pause button
- [ ] More battle maps
- [ ] Send-amount control (25% / 50% / 100%)

## Phase 2: Army upgrades

- [ ] Unit types: infantry (cheap), tanks (slow, tough), jets (fast, fragile)
- [ ] Base upgrades you can buy with captured resources (walls, turrets, bigger barracks)
- [ ] Units fighting each other when swarms collide mid-field
- [ ] Commander abilities with cooldowns (airstrike, paratroopers, supply drop)

## Phase 3: Zones

- [ ] A zone is a group of battle maps on a larger map
- [ ] Win a battle to capture its zone; holding a whole zone gives a bonus (e.g. "Industrial Zone":
      +production in every battle)
- [ ] Enemy counter-attacks on zones you hold
- [ ] Save progress on the device

## Phase 4: Countries and campaign

- [ ] Countries made of zones, each with a theme (desert, arctic, jungle, city)
- [ ] Campaign story and unlockable generals
- [ ] Multiple enemy factions with different strengths

## Later ideas

- [ ] Install to home screen as an app (PWA) with offline play
- [ ] Two-player on the same iPad
- [ ] Portrait-mode layout for phones
- [ ] Achievements and medals
